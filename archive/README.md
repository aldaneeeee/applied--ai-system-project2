# Archive

`grounded-rag/` is an earlier prototype: a retrieval-augmented Q&A system over a
few documents about AI concepts. It was **not** built on the Modules 1–3 Music
Recommender, so it is not the Project 4 submission. It is kept here for
reference only. Its tests and commands are separate from the main project and
are not run by the top-level `pytest`.

The Project 4 submission is the **Mood Catcher AI DJ** described in the
top-level [`README.md`](../README.md).
